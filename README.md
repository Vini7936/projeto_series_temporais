# projeto_series_temporais

O estudo de séries temporais é uma das aplicações mais fascinantes da Ciência de Dados, permitindo enxergar padrões ocultos, tendências de crescimento e sazonalidades ao longo do tempo.

Para expandir minhas habilidades nessa área, desenvolvi um projeto prático utilizando o clássico dataset de quantidade de passageiros de companhias aéreas (1949–1960). Foi uma experiência fantástica para entender como a análise temporal gera insights cruciais para a tomada de decisão em negócios!

 Habilidades e ferramentas desenvolvidas:
- Manipulação de dados temporais com o Pandas e tratamento específico de variáveis do tipo Datetime.
- Criação e estilização de visualizações avançadas com o Matplotlib.
- Aplicação de Decomposição de Séries Temporais para isolar e analisar seus componentes fundamentais: Tendência, Sazonalidade e Ruído.
- Análise crítica de flutuações e resíduos da base de dados.
